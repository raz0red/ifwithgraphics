# IFWG Website

A static, dependency-free build of the **Interactive Fiction with Graphics (IFWG)** marketing/catalog site: plain HTML/CSS/JS, no client framework. Styling uses the Tailwind CSS Play CDN; icons are inlined SVGs (Lucide path data) in [js/icons.js](js/icons.js).

`index.html` is a **generated file**. It's pre-rendered from the section modules in `js/sections/` so the page ships with real, crawlable HTML instead of an empty `<div id="app">` that only fills in after JS runs. Don't hand-edit `index.html`; edit the source (`index.template.html`, `js/data.js`, `js/sections/*.js`) and rebuild.

This replaces the original React/Vite app generated by Google AI Studio, which is preserved under `legacy-react/` for reference.

## Editing content

1. Edit content in `js/data.js` (games list, capabilities, steps, hero cards) or the relevant `js/sections/*.js` file.
2. Rebuild the static HTML:
   ```
   node build.js
   ```
   (or `npm run build`; no dependencies required, just Node).
3. Serve the directory to preview (see below).

## Run locally

Because the page uses ES modules, it needs to be served over HTTP rather than opened as a `file://` URL:

```
npx serve .
```

or

```
python3 -m http.server 8000
```

Then open the printed local URL.

## Structure

- `index.template.html` - source template (page shell, meta/OG tags, Tailwind + fonts) with an `<!--APP-->` marker
- `build.js` - renders each section to a string and writes the final `index.html`
- `index.html` - **generated**, do not edit directly
- `css/main.css` - custom keyframes/utility classes not covered by Tailwind (grid pan, floating pixels, card stack, scroll-reveal)
- `js/main.js` - hydration entry point: wires up the Home/Library view swap, hero card-stack hover cycle, library filters, and scroll-reveal on top of the already-static markup
- `js/sections/` - one module per section, each exporting a `renderXHTML()` string builder (used by both `build.js` and the browser) and, where needed, an `initX()` that attaches behavior to the existing DOM
- `js/data.js` - games list and page copy
- `js/icons.js` - inline SVG icon lookup
- `assets/images/` - cover/scene art
- `legacy-react/` - the original AI Studio React app, kept for reference (not built or served)

## Sections

Home view: hero (with retro card stack) → "How IFWG Operates" → "Core Capabilities" + CTA.
Library view: the Game Directory grid with filters. The two views swap client-side; both ship in the static HTML for SEO.
